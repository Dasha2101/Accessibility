# 🌐 Accessly

Инструмент для автоматизированной проверки веб-доступности, который анализирует страницы сайтов и выявляет проблемы доступности интерфейса.

Проект создан с целью повышения качества цифровых ресурсов.

## 🚀 Возможности

- Проверка alt-атрибутов изображений
- Анализ ARIA-атрибутов
- Проверка контрастности элементов
- Тестирование доступности с клавиатуры
- Анализ структуры страницы
- Проверка масштабируемости
- Анализ мультимедиа (audio/video)

## 🛠 Технологический стек

### Backend
- Node.js
- Express
- Puppeteer
- Cheerio
- Axios

### Frontend
- React
- TypeScript
- Vite

### DevOps
- Docker
- GitHub Action

## 📁 Архитектура проекта

### Backend
- src/services — сервер
- src/browser — управление Puppeteer
- src/modules — проверки доступности
- src/utils — вспомогательные функции

### Frontend
- src/components — React компоненты
- src/pages — страницы приложения
